# EazyAmortizationProject
I created a hyper specific app for amortization. This app will only work with excel sheets based off the template that comes included when downloaded.
To get application download the executable named EazyAmortization_setup_1.2.exe in the dist folder.
If Window Defender pops up click the underlined words More info and then the Run Anyway button
Make sure when picking a destination folder in the wizard that it doesn't need admin rights for uploading and writing files (e.g Program Files).
The executable files were created with the help of this tutorial https://www.youtube.com/watch?v=p3tSLatmGvU&t=660s
